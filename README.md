# Название: Умный дневник КБЖУ
Автор: Дарыбаева Розалина Азаматовна

## Что делает программа
Программа рассчитывает индивидуальную дневную норму КБЖУ на основе пола, возраста, роста, веса, физической активности и **выбранной цели (похудение, поддержание, набор массы)**. 
При выборе цели калорийность автоматически корректируется (дефицит или профицит).
Затем можно вести дневник питания и видеть, сколько осталось до цели. 
Есть отдельный калькулятор блюд.

## Как запустить
python main.py

## Проверка 1: обычный сценарий
Вход:
- Настройка профиля: пол Ж, возраст 19, рост 160, вес 47, активность 3, цель 3 (Набор массы).
- Ожидание: программа рассчитывает норму (около 2164 ккал) и выводит БЖУ (Б: ~103 г, Ж: ~66 г, У: ~289 г).
- Добавление продукта: пункт 1 → «Курица» 200г (на 100г: 200 ккал, Б 20, Ж 10, У 0).
- Ожидание: программа пересчитывает на 200г (400 ккал) и добавляет в дневник.
- Просмотр дневника (пункт 2).
Результат: программа показывает, что съедено 400 ккал, и корректно считает остаток до нормы. Совпало.

## Проверка 2 (граничный сценарий и пересчет)
Вход:
- Пункт 3 (Калькулятор). Ввод веса порции: «-50» (отрицательное число).
- Ожидание: сообщение «Значение не может быть отрицательным», запрос повторного ввода.
- Ввод веса: «abc» (буквы).
- Ожидание: сообщение «Ошибка: нужно ввести число», запрос повторного ввода.
- Ввод дробного числа через запятую (например, «150,5»).
- Ожидание: программа корректно понимает запятую и считает результат.
- Пункт 4 (пересчет нормы): выбор цели 1 (Похудение).
- Ожидание: норма калорий и БЖУ пересчитываются в меньшую сторону.
Результат: программа не падает с ошибкой, корректно обрабатывает некорректный ввод. Совпало.
